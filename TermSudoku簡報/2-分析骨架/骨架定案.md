# TermSudoku 簡報 · 骨架定案

> 場景 3 簡報工作流。ppt-classify 判型 → 引導定案 → ppt-narrative-review → ui-ux-pro-max → HTML → impeccable → PDF。
> 日期 2026-06-02。

## 類型判定
- **主類型：Teaching / How-to**（對已建成系統的結構化走查）
- **次類型：Narrative**（動機鉤子、出題器唯一解保證為突破點、心得為余韻）

## 定案參數（使用者 2026-06-02 拍板）
- 頁數：**9 頁**，~12 分鐘，每頁 1–1.5 分鐘
- Demo：**分開兩頁**（操作+驗證 / 求解+排行榜）
- 技術：**出題器單獨一頁 + 六大主題表一頁**
- 視覺：**深色終端機風**（延續舊 deck：紅黃綠圓點、等寬字、綠色 accent，呼應「終端數獨」主題）
- 輸出：本地 HTML → 匯出 **PDF**（作業限 .ppt/.pdf；不做 HTML→PPT 轉換）
- 歸檔：獨立 `~/Desktop/TermSudoku簡報/`
